# 分拣标签

技能内部使用五个规范角色。本文件把角色映射到本仓 GitHub 上的真实标签名。

| 规范角色 | 本仓标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分拣` | 维护者还没评完 |
| `needs-info` | `待补充` | 等报告人补信息 |
| `ready-for-agent` | `可交Agent` | 规格清楚，可交给无人值守 Agent |
| `ready-for-human` | `需人工` | 必须人来做 |
| `wontfix` | `不做` | 不会做 |

分类标签：

| 规范角色 | 本仓标签 | 含义 |
| --- | --- | --- |
| `bug` | `缺陷` | 坏了 |
| `enhancement` | `增强` | 新能力或改进 |

技能说到某个角色时（例如「打上可交 Agent 的分拣标签」），用本表「本仓标签」列。你们仓里已经是英文标签时，只改「本仓标签」列，不要改规范角色名。
